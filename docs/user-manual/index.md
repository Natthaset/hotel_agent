## 🏛️ สรุปบทบาทและหน้าจอการเข้าใช้งาน (Quick Access)

ระบบแบ่งส่วนติดต่อผู้ใช้ออกเป็น 2 หน้าจอหลัก:

### 1. VIP Guest Concierge Desk (`/`)
- **URL เข้าใช้งาน:** [http://localhost:3000](http://localhost:3000)
- **ผู้ใช้งาน:** แขกผู้เข้าพัก, ลูกค้าทั่วไป, แขก VIP
- **หน้าที่หลัก:**
  - สื่อสารแบบภาษาธรรมชาติ (ไทยและอังกฤษ) กับ **Aura** ผู้ช่วยคอนเซียร์จเสมือนจริง 24 ชั่วโมง
  - สอบถามนโยบาย กฎระเบียบ เวลาบริการ และสิ่งอำนวยความสะดวกของโรงแรม
  - ตรวจสอบความพร้อมของห้องพักและราคาแบบ Real-time พร้อมแสดงการ์ดห้องพัก
  - สั่งจองห้องพักและรับใบยืนยันการจอง (Booking Confirmation) ทันทีในแชต

### 2. Admin Knowledge & Vector Manager (`/admin/knowledge`)
- **URL เข้าใช้งาน:** [http://localhost:3000/admin/knowledge](http://localhost:3000/admin/knowledge)
- **ผู้ใช้งาน:** ผู้จัดการโรงแรม, ฝ่ายต้อนรับส่วนหน้า, ผู้ดูแลระบบไอที
- **หน้าที่หลัก:**
  - จัดการข้อมูลนโยบายโรงแรม (Hotel Knowledge Base)
  - เพิ่มนโยบายใหม่และแปลงเป็น Vector Embedding เข้าสู่ Qdrant อัตโนมัติ
  - ทดสอบความแม่นยำของ Semantic Search ใน Vector Playground
  - รีเซ็ตและ Re-index ข้อมูลนโยบายเริ่มต้นของโรงแรม
