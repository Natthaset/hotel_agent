## 1. ภาพรวมระบบจัดการคลังความรู้ (Knowledge Manager Overview)

ระบบจัดการคลังความรู้ ([http://localhost:3000/admin/knowledge](http://localhost:3000/admin/knowledge)) เป็นเครื่องมือสำหรับผู้บริหารโรงแรม ผู้จัดการฝ่ายต้อนรับ และทีมไอที ในการบริหารจัดการนโยบายและข้อมูลบริการของ **Grand Azure Resort & Residences** โดยจุดเด่นคือ:

- **Zero Downtime Updates:** เมื่อเพิ่มหรือแก้ไขนโยบาย ระบบจะสร้าง Vector Embedding และอัปเดตลง Qdrant ทันที ทำให้ Aura Concierge ตอบข้อมูลใหม่ได้ทันทีโดยไม่ต้องรีสตาร์ตระบบ
- **FastEmbed ONNX Engine:** ทำการแปลงข้อความเป็นเวกเตอร์ 384 มิติภายในเครื่องโดยตรง ประหยัดหน่วยความจำ VRAM 100% สำหรับโมเดลภาษา
- **Vector Search Playground:** มีสนามทดสอบการค้นหาความหมายเชิงเวกเตอร์แบบเรียลไทม์ พร้อมแสดงคะแนนความใกล้เคียง (Similarity Score %)

## 2. การเข้าสู่หน้าจอผู้ดูแลระบบ

1. เปิดเบราว์เซอร์ไปที่: `http://localhost:3000/admin/knowledge`
2. ระบบจะโหลดรายการเอกสารนโยบายที่จัดเก็บอยู่ใน Qdrant Collection `hotel_policies` ขึ้นมาแสดงผลโดยอัตโนมัติ
3. ด้านบนจะมีปุ่มลัด **`← กลับสู่หน้าหลัก VIP Concierge`** สำหรับสลับกลับไปยังหน้าจอแชตของแขก

## 3. ขั้นตอนการเพิ่มเอกสารนโยบายใหม่ด้วยการอัปโหลดไฟล์ (Add Document via File Upload)

ระบบได้รับการอัปเกรดให้รองรับการอัปโหลดไฟล์เอกสารจริงหลากหลายประเภท โดยทำการสกัดข้อความ (Text Extraction & OCR) และแนะนำหัวข้อนโยบายให้อัตโนมัติ:

### 3.1 รูปแบบไฟล์ที่รองรับ (Supported File Formats)
ระบบขับเคลื่อนด้วย **Microsoft MarkItDown Engine** ร่วมกับ Defensive OpenXML/CSV Stream Parser ทำให้ทำงานแบบ Cross-Platform 100% บน Linux Server, Docker Container, Windows และ macOS:

| ประเภทไฟล์ | นามสกุลที่รองรับ | ระบบประมวลผลภายใน |
| :--- | :--- | :--- |
| **📄 PDF** | `.pdf` | Microsoft MarkItDown (PDFMiner / PDFPlumber Engine) |
| **📝 Word** | `.docx`, `.doc` | Microsoft MarkItDown (Mammoth OpenXML Engine) |
| **📊 Excel** | `.xlsx`, `.xls` | Microsoft MarkItDown (OpenPyXL & Tabular Markdown Parser) |
| **📑 CSV** | `.csv`, `.tsv` | Microsoft MarkItDown & Pipe-delimited Tabular Parser |
| **📃 Text** | `.txt`, `.md`, `.json` | Microsoft MarkItDown & Multi-encoding Auto-detect (UTF-8, TIS-620) |
| **🖼️ Image** | `.png`, `.jpg`, `.jpeg`, `.webp` | Microsoft MarkItDown Plugin & Vision Extraction |

### 3.2 ขั้นตอนการอัปโหลดและทำ Vector Embedding:
1. **ลากหรือเลือกไฟล์:** ดูที่กล่อง **"อัปโหลดไฟล์เอกสาร (Upload Document File)"** ลากไฟล์มาวางในพื้นที่ Dropzone หรือคลิกเพื่อเลือกไฟล์จากคอมพิวเตอร์
2. **การสกัดเนื้อหาอัตโนมัติ (Instant Extraction):** 
   - ระบบจะแสดงการ์ดไฟล์ ระบุชื่อ ขนาดไฟล์ และสถานะ `✓ ดึงเนื้อหาสำเร็จ`
   - ระบบจะแนะนำ **หัวข้อเอกสาร (Policy Title)** จากชื่อไฟล์ให้อัตโนมัติ เช่น `spa_wellness_rules.pdf` → `Spa Wellness Rules`
3. **ตรวจสอบและตรวจทานเนื้อหา (Preview & Edit):** 
   - เนื้อหาที่ดึงมาจากไฟล์จะปรากฏในช่อง **"เนื้อหารายละเอียดที่สกัดได้ (Document Content)"**
4. **บันทึกลงคลังความรู้:** คลิกปุ่ม **`✦ Generate Embeddings & Save to Qdrant`** เพื่อสร้างเวกเตอร์ 384 มิติด้วย FastEmbed และบันทึกลง Qdrant ทันที
5. ระบบจะแสดง **Popup Alert แจ้งเตือนความสำเร็จ** ตรงกลางหน้าจอ (เช่น `สร้าง Embedding และบันทึกลง Qdrant สำเร็จ: "ราคาสปา"`) พร้อมรายละเอียดเวกเตอร์ และเอกสารใหม่จะปรากฏในตารางคลังความรู้ด้านล่างทันที

## 4. การทดสอบการค้นหาเชิงเวกเตอร์ (Vector Search Playground)

เพื่อความมั่นใจว่าเมื่อแขกสอบถาม Aura จะสามารถดึงข้อมูลที่เพิ่งเพิ่มไปใช้งานได้อย่างถูกต้อง ให้ใช้เครื่องมือทดสอบฝั่งขวา:

1. ดูที่กล่อง **"🔍 ทดสอบค้นหาความหมายเชิงเวกเตอร์ (Vector Search Playground)"**
2. **พิมพ์คำค้นหา (Query):** พิมพ์คำถามหรือคำค้นหาภาษาไทย/อังกฤษ เช่น:
   > *จัดงานแต่งงานริมทะเลได้กี่คน*
3. **กำหนดจำนวนผลลัพธ์ (Top-K):** เลื่อนแถบตัวเลข Top-K (แนะนำที่ 3 หรือ 5 รายการ)
4. คลิกปุ่ม **`ทดสอบค้นหา (Test Search)`**
5. **การอ่านผลลัพธ์การค้นหา:**
   - **Similarity Score (%):** แสดงค่าความแม่นยำของ Cosine Similarity (เช่น 85.4% หรือ 91.2%)
   - **Rank #1, #2, #3:** เรียงลำดับเอกสารที่ตรงกับความหมายของคำถามมากที่สุด
   - **Document Preview:** แสดงเนื้อหาที่ระบบจะส่งให้ LLM ใช้อ้างอิงในการตอบแขก

> [!TIP]
> หากคะแนนความใกล้เคียงมากกว่า **70% ขึ้นไป** ถือว่ามีความแม่นยำสูงมาก และ AI Concierge จะนำข้อมูลดังกล่าวไปตอบแขกได้อย่างถูกต้องแน่นอน

## 5. การลบเอกสารและคืนค่าเริ่มต้น (Delete & Re-Index)

### การลบเอกสารรายฉบับ (Delete Document):
1. เลื่อนลงมาที่ตาราง **"รายการเอกสารนโยบายปัจจุบัน"**
2. ค้นหาเอกสารที่ต้องการลบ แล้วคลิกปุ่ม **`🗑️ ลบ`** ด้านขวามือของแถวนั้น
3. กล่องยืนยันจะปรากฏขึ้น ให้กด **`ตกลง (OK)`** เพื่อยืนยันการลบ Vector Point ออกจาก Qdrant

### การรีเซ็ตนโยบายเริ่มต้น (Re-index Default Policies):
- หากมีการทดสอบข้อมูลชั่วคราวเป็นจำนวนมาก และต้องการล้างข้อมูลเพื่อกลับสู่ชุดนโยบายมาตรฐาน 8 ฉบับของโรงแรม
- ให้คลิกที่ปุ่ม **`🔄 Re-index นโยบายเริ่มต้น`** บริเวณมุมขวาบนของตาราง
- กดยืนยันในกล่องข้อความ ระบบจะทำการลบข้อมูลเก่าและ Seed ชุดนโยบายมาตรฐานกลับมาให้ครบถ้วนในไม่กี่วินาที

## 6. ข้อควรปฏิบัติและแนวทางแก้ไขเมื่อ AI ตอบข้อมูลไม่ครบถ้วน (Best Practices & Troubleshooting)

ในระบบ RAG (Retrieval-Augmented Generation) หากพบว่า AI Concierge ตอบข้อมูลไม่ครบถ้วน (เช่น มีรายการทรีตเมนต์ 3 รายการ แต่ AI ตอบเพียง 2 รายการ หรือเงื่อนไขบางข้อตกหล่น) มักเกิดจากปัจจัยด้านโครงสร้างข้อความและการจัดรูปแบบในเอกสารต้นฉบับ

### 6.1 สาเหตุหลักที่ทำให้ AI ตอบตกหล่น
1. **ขาดเครื่องหมายลำดับข้อ (Lack of Explicit Numbering):**
   - ข้อความที่เขียนติดกันเป็นย่อหน้ายาวๆ หรือใช้เพียง bullet ที่ไม่มีหมายเลข ทำให้โมเดล LLM อาจจัดกลุ่มข้อความผิดพลาด
2. **ความไม่สมมาตรของไวยากรณ์ (Semantic Asymmetry):**
   - เช่น รายการที่ 1 และ 2 ระบุทั้ง "ระยะเวลา" และ "ราคาตัวเลข" แต่รายการที่ 3 ไม่ได้ระบุราคาเป็นตัวเลข (ระบุว่าเป็น "บริการฟรีสำหรับแขกห้อง Suite")
   - LLM มักจะตีความว่า 2 ข้อแรกคือ *"รายการบริการหลัก (Treatments)"* ส่วนข้อที่ 3 คือ *"สิทธิพิเศษ/สิ่งอำนวยความสะดวก (Privilege/Amenity)"* จึงไม่นำมาตอบในรายการหลัก
3. **การใช้คำเรียกหมวดหมู่ไม่ตรงกัน:**
   - การไม่ระบุคำว่า "ทรีตเมนต์" หรือ "บริการ" กำกับไว้ในชื่อรายการ ทำให้ LLM ลังเลที่จะนับรวมเป็นทรีตเมนต์

### 6.2 ตัวอย่างการจัดรูปแบบเอกสาร (Formatting Examples)

#### ❌ ตัวอย่างที่ไม่แนะนำ (เสี่ยงต่อการที่ AI จะตอบตกหล่น)
```text
1. ทรีตเมนต์ยอดนิยมและอัตราค่าบริการ
การนวดไทยราชสำนักโบราณ (90 นาที): ราคา 3,200 บาท ช่วยคลายกล้ามเนื้อและความเมื่อยล้า
อโรมาเธอราพีด้วยหินภูเขาไฟร้อน (120 นาที): ราคา 4,500 บาท ใช้น้ำมันหอมระเหยออร์แกนิกเกรดพรีเมียม
การแช่น้ำแข็งเพื่อฟื้นฟูสุขภาพ (Ice Plunge Bath) & ซาวน่าเกลือหิมาลายัน: ฟรีสำหรับแขกห้อง Suite และ Villa
```
> *ปัญหา:* รายการที่ 3 ไม่มีคำระบุประเภท และไม่มีโครงสร้างราคาที่ชัดเจน ทำให้ AI ตอบแค่ 2 ข้อแรก

#### ✅ ตัวอย่างที่แนะนำ (AI ตอบครบถ้วน 100%)
```text
1. รายการทรีตเมนต์และโปรแกรมฟื้นฟูสุขภาพยอดนิยม
- ทรีตเมนต์ที่ 1: การนวดไทยราชสำนักโบราณ (90 นาที): ราคา 3,200 บาท ช่วยคลายกล้ามเนื้อและความเมื่อยล้า
- ทรีตเมนต์ที่ 2: อโรมาเธอราพีด้วยหินภูเขาไฟร้อน (120 นาที): ราคา 4,500 บาท ใช้น้ำมันหอมระเหยออร์แกนิกเกรดพรีเมียม
- ทรีตเมนต์ที่ 3: การแช่น้ำแข็งเพื่อฟื้นฟูสุขภาพ (Ice Plunge Bath) & ซาวน่าเกลือหิมาลายัน: บริการทรีตเมนต์ฟื้นฟูสุขภาพ (ฟรีสำหรับแขกห้อง Suite และ Villa / แขกทั่วไปสามารถสอบถามอัตราค่าบริการได้ที่เคาน์เตอร์สปา)
```
> *ข้อดี:* ระบุคำว่า "ทรีตเมนต์ที่ 1, 2, 3" ไว้อย่างชัดเจน ทำให้โมเดล LLM เข้าใจบริบทและดึงไปแจกแจงได้ครบถ้วนทุกข้อ

### 6.3 ขั้นตอนการแก้ไขปัญหาสำหรับ Admin (Step-by-Step Resolution)
1. **ตรวจสอบด้วย Vector Search Playground:**
   - ในหน้า Admin Knowledge ให้พิมพ์คำถามเดียวกับที่ลูกค้าถามในช่อง **Vector Search Playground** ทางขวามือ
   - สังเกตว่าเอกสารที่ระบบดึงมามีเนื้อหาครอบคลุมหรือไม่ และ Similarity Score สูงกว่า 60% หรือไม่
2. **ปรับปรุงและจัดโครงสร้างข้อความใหม่:**
   - นำข้อความเดิมมาเติมหมายเลขข้อ กำกับชื่อประเภทให้ชัดเจน และปรับโครงสร้างประโยคให้มีความสม่ำเสมอ
3. **บันทึกทับหรือลบสร้างใหม่:**
   - เลื่อนลงมาที่ตารางเอกสารด้านล่าง กดปุ่ม **`🗑️ ลบ`** เอกสารฉบับเดิม
   - กรอกหรืออัปโหลดข้อความฉบับปรับปรุงใหม่ แล้วคลิก **`✦ Generate Embeddings & Save to Qdrant`**
4. **ทดสอบแชตจริง:**
   - สลับกลับไปที่หน้า Concierge Chat เพื่อทดสอบถามคำถามเดิมซ้ำ และตรวจสอบว่า Aura ตอบข้อมูลได้ครบถ้วน
