## 1. วิธีการสั่งจองห้องพัก (Room Booking Steps)

แขกผู้เข้าพักสามารถดำเนินการจองห้องพักได้ 2 รูปแบบตามความสะดวก:

### วิธีที่ 1: การจองผ่านปุ่มกดบนการ์ดห้องพัก (One-Click Booking) — แนะนำ
1. เมื่อระบบแสดงการ์ดห้องพักที่ตรงกับความต้องการ ให้ดูการ์ดห้องพักที่ท่านพึงพอใจ
2. คลิกที่ปุ่ม **`จองห้องนี้ทันที`** ด้านล่างของการ์ดห้องพักนั้น
3. ระบบจะสร้างข้อความคำสั่งจองพร้อมกรอกชื่อห้องและรหัสห้องลงในกล่องแชตให้อัตโนมัติ เช่น:
   > *"ช่วยจองห้อง Deluxe Ocean View (รหัสห้อง: 1) ในชื่อคุณ Palm สำหรับ 2 ท่าน ตั้งแต่วันที่ 2026-10-01 ถึง 2026-10-04 ให้หน่อยครับ"*
4. ตรวจสอบข้อมูลแล้วกดปุ่ม **`➔` (Send)** เพื่อยืนยันการจอง

### วิธีที่ 2: การสั่งจองผ่านข้อความแชตโดยตรง (Natural Language Booking)
แขกสามารถพิมพ์ความประสงค์ในการจองลงในช่องแชตได้ตลอดเวลา โดยระบุข้อมูลสำคัญให้ครบถ้วน:
- **ข้อมูลที่จำเป็นสำหรับการจอง:**
  1. ชื่อ-นามสกุลของผู้เข้าพักหลัก (เช่น คุณศิริพร หรือ Dr. Thanawat)
  2. ประเภทห้องพัก หรือ รหัสห้อง (เช่น Penthouse หรือ รหัสห้อง 1)
  3. วันที่เช็คอิน และ วันที่เช็คเอาต์ (เช่น วันที่ 10 ถึง 13 ตุลาคม 2026)
  4. จำนวนผู้เข้าพัก (เช่น 2 ท่าน)
- **ตัวอย่างข้อความ:**
  > *"ช่วยจองห้อง Grand Executive Suite สำหรับคุณสมชาย 2 ท่าน เช็คอิน 15 พ.ย. เช็คเอาต์ 18 พ.ย. 2026 เบอร์โทร 0812345678 ครับ"*

## 2. การอ่านใบยืนยันการจองห้องพัก (Booking Confirmation Card)

เมื่อระบบทำการบันทึกข้อมูลการจองลงฐานข้อมูลเสร็จสมบูรณ์ ระบบจะส่ง **การ์ดใบยืนยันการจองดิจิทัล** เข้ามาในแชตทันที:

```text
┌────────────────────────────────────────────────────────┐
│  ✔ BOOKING CONFIRMED — GRAND AZURE RESORT             │
│                                                        │
│  รหัสอ้างอิงการจอง: #BK-1004                           │
│  ชื่อผู้เข้าพักหลัก: คุณสมชาย ใจดี                         │
│  ประเภทห้อง: Grand Executive Suite                      │
│  ───────────────────────────────────────────────────── │
│  เช็คอิน:  15 พ.ย. 2026 (15:00 น.)                    │
│  เช็คเอาต์: 18 พ.ย. 2026 (12:00 น.)                    │
│  ระยะเวลา: 3 คืน | ผู้เข้าพัก: 2 ท่าน                  │
│  ───────────────────────────────────────────────────── │
│  ยอดรวมสุทธิ: 25,500.00 THB (รวมภาษีและค่าบริการแล้ว)      │
│  สถานะ: ยืนยันเรียบร้อย (Confirmed)                      │
└────────────────────────────────────────────────────────┘
```

### รายละเอียดในใบยืนยัน:
1. **รหัสอ้างอิงการจอง (Booking Reference ID):** ใช้สำหรับอ้างอิงเมื่อเดินทางมาถึงฟร้อนท์เดสก์ของโรงแรม
2. **ข้อมูลวัน-เวลาเข้าพัก:** ระบุวันเช็คอิน วันเช็คเอาต์ และจำนวนคืนรวมอย่างชัดเจน
3. **ยอดรวมสุทธิ (Total Price):** ยอดเงินรวมที่คำนวณจากราคาห้องต่อคืน × จำนวนคืน
4. **สถานะการจอง:** แสดงสถานะยืนยัน (`Confirmed`) พร้อมบันทึกเข้าสู่ระบบจัดการโรงแรมส่วนกลาง

## 3. กฎความถูกต้องทางธุรกิจและการตรวจสอบ (Business Rules)

ระบบ .NET Core Backend มีการตรวจสอบความถูกต้องของข้อมูลตามมาตรฐานโรงแรมระดับ 5 ดาวอย่างเคร่งครัด:

| กฎทางธุรกิจ (Business Rule) | ข้อกำหนดของระบบ | ผลลัพธ์หากไม่ผ่านเงื่อนไข |
| :--- | :--- | :--- |
| **วันที่เช็คอิน (Check-In)** | ต้องเป็นวันปัจจุบันหรือวันในอนาคตเท่านั้น | แจ้งเตือน: ไม่สามารถจองวันที่ย้อนหลังได้ |
| **วันที่เช็คเอาต์ (Check-Out)** | ต้องอยู่หลังวันที่เช็คอินอย่างน้อย 1 คืน | แจ้งเตือน: วันที่เช็คเอาต์ต้องมากกว่าวันเช็คอิน |
| **ระยะเวลาพักสูงสุด** | ไม่เกิน 30 คืนต่อการจอง 1 ครั้ง | แจ้งเตือน: กรุณาติดต่อฝ่ายขายสำหรับการพักระยะยาว |
| **ความจุห้องพัก (Capacity)** | จำนวนคนต้องไม่เกินที่ห้องพักรองรับ | แจ้งเตือน: ห้องพักนี้รองรับได้สูงสุดตามกำหนด |
| **การจองซ้ำซ้อน (Conflict)** | ห้องพักต้องว่างตลอดช่วงวันที่เลือก | แจ้งเตือน: ห้องพักถูกจองเต็มแล้วในช่วงวันดังกล่าว |

## 4. ตัวอย่างสถานการณ์การใช้งานจริง (Real-World Scenarios)

### สถานการณ์ที่ 1: สอบถามสิ่งอำนวยความสะดวกแล้วจองต่อเนื่อง
> **แขก:** *"สระว่ายน้ำปิดกี่โมง และห้องพักมีเตียงเด็กเล็กไหมครับ"*  
> **Aura:** *"สระว่ายน้ำหลักวิวพาโนรามาเปิดให้บริการ 06:00 – 21:00 น. ค่ะ และทางโรงแรมมีบริการเตียงเด็กเล็ก (Baby Cot) ฟรีสำหรับทุกประเภทห้องพัก เพียงแจ้งล่วงหน้าค่ะ วันนี้สนใจให้ดิฉันตรวจสอบห้องพักให้เลยไหมคะ?"*  
> **แขก:** *"งั้นช่วยจองห้อง Deluxe Ocean View ให้คุณอนันต์ 2 ท่าน วันที่ 5-7 ธันวาคม 2026 ครับ"*  
> **Aura:** *"ยินดีเป็นอย่างยิ่งค่ะ ดำเนินการจองห้อง Deluxe Ocean View ให้คุณอนันต์เรียบร้อยแล้วค่ะ [แสดงการ์ดใบยืนยัน #BK-1005]"*

### สถานการณ์ที่ 2: การแจ้งเตือนเมื่อจำนวนคนเกินความจุห้อง
> **แขก:** *"ต้องการจองห้อง Deluxe Room สำหรับ 6 ท่าน วันที่ 12-14 พ.ย. นี้ครับ"*  
> **Aura:** *"ขออภัยเป็นอย่างยิ่งค่ะ ห้อง Deluxe Room สามารถรองรับผู้เข้าพักได้สูงสุด 2 ท่านค่ะ สำหรับกลุ่ม 6 ท่าน ดิฉันขอแนะนำเป็น 'Royal Beachfront Villa' ซึ่งรองรับได้สูงสุด 6 ท่านพอดีค่ะ สนใจให้ดิฉันตรวจสอบความพร้อมของวิลล่านี้แทนไหมคะ?"*
