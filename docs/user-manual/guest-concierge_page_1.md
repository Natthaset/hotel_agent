## 1. ภาพรวมหน้าจอ VIP Concierge Desk

หน้าจอ VIP Concierge Desk ([http://localhost:3000](http://localhost:3000)) ถูกออกแบบมาเพื่อให้แขกผู้เข้าพักได้รับประสบการณ์เสมือนมีผู้ช่วยส่วนตัว (Virtual Butler) คอยดูแลอำนวยความสะดวกตลอด 24 ชั่วโมง โดยมีจุดเด่นคือ:

- **การสนทนาโต้ตอบแบบ Real-time:** แสดงข้อความคำตอบแบบ Token Streaming ไหลลื่นเสมือนพิมพ์ตอบสด
- **Aura Executive Concierge:** ปัญญาประดิษฐ์ที่ได้รับการปรับแต่งสำนวนให้สุภาพ หรูหรา อบอุ่น และใส่ใจในรายละเอียด
- **การ์ดข้อมูลตอบสนองเชิงโต้ตอบ (Interactive UI):** แสดงรูปภาพห้องพัก รายละเอียดราคา และใบยืนยันการจองในรูปแบบการ์ดที่สวยงามทันทีในกล่องข้อความ

```text
┌────────────────────────────────────────────────────────┐
│ Grand Azure Resort & Residences                        │
│ ────────────────────────────────────────────────────── │
│ [✨ Aura — Executive Concierge]        [Desk: VIP Service] │
│                                                        │
│ Aura: ยินดีต้อนรับสู่ Grand Azure Resort...            │
│ Guest: มีห้องว่างช่วงสุดสัปดาห์นี้ไหมครับ?             │
│ Aura: ได้ค่ะ ทางเรามีห้องว่างดังนี้ค่ะ...              │
│       [ การ์ดห้องพัก: Deluxe Ocean View ]              │
│       [ การ์ดห้องพัก: Royal Beachfront Villa ]         │
│                                                        │
│ [🕒 เวลาเช็คอิน] [🛏️ ตรวจห้องว่าง] [🍽️ อาหารเช้า] [🐾 สัตว์เลี้ยง] │
│ ┌────────────────────────────────────────┬───────────┐ │
│ │ พิมพ์ข้อความสอบถามห้องว่าง นโยบาย...   │    ➔      │ │
│ └────────────────────────────────────────┴───────────┘ │
└────────────────────────────────────────────────────────┘
```

## 2. การเริ่มต้นใช้งานและการส่งข้อความ

1. **เข้าสู่หน้าเว็บ:** เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
2. **ข้อความต้อนรับ:** เมื่อเปิดหน้าจอขึ้นมา ระบบจะแสดงข้อความทักทายจาก **Aura** โดยอัตโนมัติ
3. **การพิมพ์ข้อความ:** 
   - คลิกที่ช่องกรอกข้อความด้านล่าง (Placeholder: *"พิมพ์ข้อความสอบถามห้องว่าง นโยบาย หรือสั่งจองห้องพัก..."*)
   - พิมพ์คำถามหรือความต้องการเป็นภาษาไทยหรือภาษาอังกฤษ
   - กดปุ่ม **`Enter`** บนคีย์บอร์ด หรือคลิกปุ่ม **`➔` (Send)** เพื่อส่งข้อความ
4. **การรักษาสถานะการสนทนา (Session Continuity):**
   - ระบบจะจดจำ `thread_id` ของคุณไว้ในเบราว์เซอร์อัตโนมัติ ทำให้สามารถสนทนาต่อเนื่องได้แม้มีการรีเฟรชหน้าจอ

## 3. การใช้งานชิปคำถามด่วน (Quick Action Chips)

หากคุณไม่ต้องการพิมพ์ข้อความยาว สามารถคลิกเลือก **Quick Action Chips** ที่แถบเหนือช่องพิมพ์ข้อความได้ทันที:

| สัญลักษณ์และชื่อชิป | คำถามที่ระบบส่งให้อัตโนมัติ | จุดประสงค์ |
| :--- | :--- | :--- |
| **🕒 เวลาเช็คอิน & เช็คเอาต์** | *"เวลาเช็คอินและเช็คเอาต์ของโรงแรมกี่โมง มีบริการ Early check-in ไหมครับ?"* | ตรวจสอบเวลารับห้อง คืนห้อง และค่าธรรมเนียมเข้าก่อนเวลา |
| **🛏️ ตรวจสอบห้องว่างสัปดาห์นี้** | *"ช่วยตรวจสอบห้องพักว่างสำหรับ 2 ท่าน ในสุดสัปดาห์นี้ให้หน่อยครับ"* | ค้นหาห้องว่างและราคาโปรโมชั่นในสัปดาห์ปัจจุบัน |
| **🍽️ อาหารเช้า & บุฟเฟต์** | *"อาหารเช้าให้บริการกี่โมง มีเมนูอะไรบ้าง รวมอยู่ในค่าห้องไหมครับ?"* | ข้อมูลห้องอาหาร Azure Verandah และเวลาเปิดให้บริการ |
| **🐾 นโยบายสัตว์เลี้ยง** | *"โรงแรมอนุญาตให้นำสัตว์เลี้ยงเข้าพักได้ไหม และมีเงื่อนไขอย่างไรบ้างครับ?"* | กฎการพาสัตว์เลี้ยงเข้าพัก โซนที่อนุญาต และค่ามัดจำ |
| **🚗 รถรับ-ส่งสนามบิน** | *"มีบริการรถรับส่งสนามบินไหม ค่าบริการเท่าไหร่ครับ?"* | บริการรถลีมูซีนรับ-ส่งสนามบินนานาชาติภูเก็ต |
| **❌ นโยบายการยกเลิกการจอง** | *"นโยบายการยกเลิกห้องพักเป็นอย่างไร ต้องแจ้งล่วงหน้ากี่ชั่วโมงครับ?"* | เงื่อนไขการยกเลิกห้องฟรี และนโยบายคืนเงิน |

## 4. การสอบถามนโยบายและข้อมูลบริการ (Policy & Amenities Inquiry)

เมื่อแขกถามคำถามเกี่ยวกับโรงแรม ระบบจะส่งคำถามไปยัง **AI RAG Engine** เพื่อค้นหาข้อมูลที่ตรงกันที่สุดจากฐานข้อมูลเวกเตอร์ (Qdrant) และตอบกลับอย่างแม่นยำ:

- **ตัวอย่างคำถามที่สามารถถามได้:**
  - *"สระว่ายน้ำเปิดกี่โมงและปิดกี่โมงครับ?"*
  - *"ห้องฟิตเนสมีเทรนเนอร์คอยดูแลไหม?"*
  - *"มีบริการอาหารแบบ Halal หรือ มังสวิรัติ ในบุฟเฟต์ไหมครับ?"*
  - *"สามารถขอ Late Check-out ได้ถึงกี่โมง และมีค่าใช้จ่ายเท่าไหร่?"*

> **จุดเด่น:** Aura จะไม่ตอบเดาข้อเท็จจริง หากเป็นเรื่องที่ไม่มีในนโยบายของโรงแรม ระบบจะแนะนำให้ติดต่อเจ้าหน้าที่ต้อนรับส่วนหน้าอย่างสุภาพ

## 5. การตรวจสอบห้องพักว่าง (Room Availability)

เมื่อแขกต้องการทราบห้องว่าง สามารถระบุวันที่ต้องการเข้าพักและจำนวนผู้เข้าพักในแชตได้โดยตรง:

### รูปแบบคำถามที่แนะนำ:
- *"มีห้องว่างช่วงวันที่ 1 ถึง 4 ตุลาคม 2026 ไหมครับ มากัน 2 คน"*
- *"ขอทราบห้องพักว่างสุดสัปดาห์หน้า สำหรับครอบครัว 4 ท่านครับ"*
- *"ต้องการห้องพักคืนวันพรุ่งนี้ 1 คืน มีห้องแบบไหนบ้าง"*

### สิ่งที่ระบบจะแสดงผล:
ระบบจะประมวลผลผ่าน .NET Core Backend และส่งข้อมูลห้องพักกลับมาแสดงเป็นการ์ดห้องพัก (**Interactive Room Cards**) ประกอบด้วย:
1. **รูปภาพทัศนียภาพห้องพักจริง**
2. **ชื่อประเภทห้องพัก** (เช่น Deluxe Ocean View, Grand Executive Suite, Royal Beachfront Villa)
3. **รายละเอียดเตียงและขนาดห้อง** (เช่น King Bed, 65 ตร.ม.)
4. **จำนวนผู้เข้าพักสูงสุด** (Max Capacity)
5. **ราคาต่อคืน (THB)** พร้อมป้ายภาษีและค่าบริการ
6. **แท็กสิ่งอำนวยความสะดวก** (เช่น ระเบียงส่วนตัว, อ่างจากุซซี่, สระว่ายน้ำส่วนตัว)
7. **ปุ่มกด "จองห้องนี้ทันที" (Book Now)**
