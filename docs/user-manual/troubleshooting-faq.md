## 1. คำถามที่พบบ่อย (Frequently Asked Questions - FAQ)

### Q1: Aura AI Concierge รองรับการสื่อสารภาษาใดบ้าง?
**ตอบ:** Aura รองรับภาษาไทยและภาษาอังกฤษเป็นหลัก โดยได้รับการปรับแต่งสำนวนการพูดให้เหมาะสมกับธุรกิจการบริการระดับ 5 ดาว มีความสุภาพ นุ่มนวล และเข้าใจภาษาพูดทั่วไปได้อย่างแม่นยำ

### Q2: ข้อมูลการจองห้องพักถูกจัดเก็บที่ใด และมีความน่าเชื่อถือเพียงใด?
**ตอบ:** ข้อมูลการจองห้องพักทุกรายการจะถูกส่งผ่าน Business Logic Service ของ .NET 10 API และบันทึกเข้าสู่ฐานข้อมูล **MySQL** โดยตรงแบบ Transactional Integrity ทำให้ข้อมูลการจองมีรหัสอ้างอิงชัดเจน และซิงค์กับแผนกต้อนรับส่วนหน้าทันที

### Q3: หากต้องการเปลี่ยนข้อมูลหรือยกเลิกการจองที่ทำผ่านแชต ต้องทำอย่างไร?
**ตอบ:** ในเวอร์ชันปัจจุบัน แขกสามารถติดต่อเจ้าหน้าที่ต้อนรับส่วนหน้า (Front Desk) หรือโทรศัพท์แจ้งรหัสอ้างอิงการจอง (`#BK-XXXX`) เพื่อดำเนินการเปลี่ยนแปลงหรือขอยกเลิกได้ตลอด 24 ชั่วโมงตามเงื่อนไขนโยบายการยกเลิกห้องพัก

### Q4: สามารถสอบถามข้อมูลเรื่องอื่นๆ ที่ไม่ได้เกี่ยวกับห้องพักได้หรือไม่?
**ตอบ:** ได้ค่ะ Aura สามารถตอบข้อมูลสิ่งอำนวยความสะดวกในโรงแรม เช่น เวลาเปิด-ปิดห้องฟิตเนส สระว่ายน้ำ กฎการพาสัตว์เลี้ยงเข้าพัก อัตราค่าบริการรถรับ-ส่งสนามบิน และเมนูอาหารเช้า โดยข้อมูลทั้งหมดจะถูกอัปเดตตรงจากคลังความรู้นโยบายโรงแรมเสมอ

## 2. การแก้ไขปัญหาเบื้องต้น (Troubleshooting Guide)

### ปัญหาที่ 1: ข้อความแจ้งเตือน "ระบบเชื่อมต่อฐานข้อมูลการบริการขัดข้องชั่วคราว..."
- **สาเหตุ:** เบราว์เซอร์ไม่สามารถเชื่อมต่อไปยัง AI Orchestrator (Port 8000) หรือ .NET Web API (Port 8080) ได้
- **วิธีตรวจสอบและแก้ไข:**
  1. ตรวจสอบว่าคอนเทนเนอร์หรือโปรเซสกำลังทำงานอยู่หรือไม่:
     ```bash
     docker compose ps
     ```
  2. ตรวจสอบ Health Endpoint ของทั้งสองบริการผ่านเบราว์เซอร์:
     - .NET API Health: [http://localhost:8080/health](http://localhost:8080/health) (ต้องตอบ `Healthy`)
     - AI Orchestrator Health: [http://localhost:8000/health](http://localhost:8000/health) (ต้องตอบ `{"status": "ok"}`)
  3. หากรันใน Docker ให้ตรวจสอบ Logs:
     ```bash
     docker compose logs -f ai-agent dotnet-api
     ```

### ปัญหาที่ 2: ระบบตอบว่า "ไม่พบห้องพักว่างในช่วงวันที่ดังกล่าว"
- **สาเหตุ:** 
  1. ห้องพักประเภทนั้นมีผู้จองเต็มแล้วในช่วงวันที่เลือก
  2. ระบุวันที่ในอดีต หรือวันที่เช็คเอาต์อยู่ก่อนวันที่เช็คอิน
- **วิธีแก้ไข:** ลองระบุช่วงวันใหม่ในอนาคต หรือสอบถามแบบไม่ระบุประเภทห้องเพื่อให้ระบบแสดงห้องพักว่างทุกประเภทที่มีอยู่

### ปัญหาที่ 3: ต้องการเริ่มต้นบทสนทนาใหม่ทั้งหมด (Reset Session)
- **สาเหตุ:** ต้องการล้างบริบทเดิมและเริ่มคุยเหมือนเข้ามาใช้งานครั้งแรก
- **วิธีแก้ไข:**
  - กดปุ่ม Refresh หน้าจอเบราว์เซอร์ (F5 หรือ Cmd+R)
  - หรือกดปุ่มเปิดแท็บใหม่ในโหมดไม่ระบุตัวตน (Incognito Window)
  - หรือเปิด DevTools ของเบราว์เซอร์ → Application → Local Storage แล้วลบค่าคีย์ `concierge_thread_id`

### ปัญหาที่ 4: AI ตอบข้อมูลไม่ครบถ้วน หรือตอบตกหล่นบางรายการ (เช่น มีทรีตเมนต์ 3 ข้อ แต่ตอบแค่ 2 ข้อ)
- **สาเหตุ:**
  1. ข้อความในเอกสารคลังความรู้ไม่มีการกำกับลำดับข้อ หรือเขียนเป็นย่อหน้าติดกัน
  2. โครงสร้างข้อมูลแต่ละข้อไม่สมมาตร (เช่น บางข้อระบุราคาตัวเลขชัดเจน แต่บางข้อระบุเป็นคำว่า "ฟรี / สิทธิพิเศษ") ทำให้โมเดล LLM ตีความว่าเป็นสิ่งอำนวยความสะดวกหรือหมายเหตุ ไม่นับเป็นรายการบริการหลัก
  3. มีเอกสารอื่นในระบบที่มีคีย์เวิร์ดทับซ้อนและได้คะแนนความคล้ายคลึงสูงกว่า
- **วิธีแก้ไข:**
  1. เข้าสู่หน้าจอ [Admin Knowledge Manager](http://localhost:3000/admin/knowledge) แล้วทดสอบค้นหาด้วยคำถามที่พบปัญหาในช่อง **Vector Search Playground**
  2. ปรับปรุงโครงสร้างข้อความเอกสารต้นฉบับให้มีลำดับข้อและคำนำหน้าชัดเจน เช่น `- ทรีตเมนต์ที่ 1: ...`, `- ทรีตเมนต์ที่ 2: ...`, `- ทรีตเมนต์ที่ 3: ...`
  3. กดปุ่ม `🗑️ ลบ` เอกสารฉบับเดิมในตาราง Qdrant แล้วบันทึกสร้างเวกเตอร์ฉบับปรับปรุงใหม่
  4. ศึกษารูปแบบตัวอย่าง Best Practice ได้ใน [บทที่ 2: หัวข้อ 6.2](admin-knowledge.md#62-ตัวอย่างการจัดรูปแบบเอกสาร-formatting-examples)

| :--- | :---: | :--- | :--- |
| **SvelteKit Chat UI** | `3000` | [http://localhost:3000](http://localhost:3000) | หน้าจอแชต VIP Concierge สำหรับแขก |

| **Qdrant Vector Dashboard** | `6333` | [http://localhost:6333/dashboard](http://localhost:6333/dashboard) | แดชบอร์ดตรวจสอบเวกเตอร์และคอลเลกชัน |
